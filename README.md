# Employee Management System – SQL Project

## 📌 Project Overview
The Employee Management System is a SQL-based database project designed to manage employee information efficiently. It demonstrates database design, table creation, relationships, constraints, and SQL queries used to solve real-world business problems.

This project was developed as part of my SQL learning journey to strengthen my skills in database management and SQL query writing.

---

## 🎯 Objective
- Design a relational database for employee management.
- Store and manage employee-related information.
- Perform data retrieval and analysis using SQL queries.
- Demonstrate SQL concepts such as joins, aggregate functions, subqueries, views, and stored procedures.

---

## 🛠️ Technologies Used
- SQL
- MySQL
- MySQL Workbench

---

## 📂 Database Tables
- Departments
- Employees
- Projects
- Salaries
- Attendance

---

## 📚 SQL Concepts Covered
- Database Creation
- Table Creation
- Primary Keys & Foreign Keys
- Constraints
- INSERT, UPDATE & DELETE
- SELECT Queries
- WHERE, ORDER BY, GROUP BY, HAVING
- INNER JOIN, LEFT JOIN
- Aggregate Functions
- Subqueries
- Views
- Stored Procedures

---

## 📊 Business Problems Solved
- Find employees with the highest salary.
- Count employees in each department.
- Calculate average salary by department.
- Identify employees working on multiple projects.
- Retrieve attendance details.
- Display department-wise employee information.
- Analyze salary distribution.

---

- Designed a normalized relational database.
- Improved SQL query writing skills.
- Understood relationships between multiple tables.
- Practiced solving real-world business scenarios using SQL.
- Gained hands-on experience with joins, subqueries, and aggregate functions.
